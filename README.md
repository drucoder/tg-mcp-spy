# Телеграм шпиён-суммрайзер

Данный MCP сервер даёт возможность сформировать список подписок на телеграм каналы.
Он запрашивает обновления каналов http запросами вида https://t.me/s/letsCode_Dru,
парсит html и сохраняет в локальном кэше.

Пагинация осуществляется через указание номера поста в параметре `before`: /s/letsCode_Dru?before=523,
где номер - это ID поста.

Клиент может добавлять и удалять каналы. Также клиент может запрашивать конкретный пост,
все посты за период по каналу или всем каналам.
